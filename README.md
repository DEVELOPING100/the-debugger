## Working Locally

Git is a version control system that allows developers to track changes to files and work on projects over time. Important Git concepts include repositories, commits, branches, and the working directory.

A repository stores the files and history of a project. A commit saves a snapshot of changes, while branches allow developers to work on different versions of a project without affecting the main branch.


## Working Remotely
  Git allows developers to collaborate on project using remote repositories hosted on platform such as GitHub. The remote repository stores a shared copy of the project that team members can access.
i
  Important commands include 'git clone' to copy a repository,'git push' to upload local commits, 'git pull' to retireve and integrate changes, and 'git fetch' to download remote updates without automatically merging them.
